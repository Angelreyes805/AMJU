# new-websiote

Working directory for website / SEO work related to [AMJ Unlimited](https://www.amjunlimited.com).

## Notes
- The live site is built on Wix. Most SEO settings (title, meta description, Open Graph, structured data) are managed in Wix under **SEO Tools → SEO Settings** and the **Structured Data / Custom Code** editor.

## SEO audit summary (2026-08-21)
- Homepage `<title>` is the weak Wix default `Hobby | Amjunlimited` — rewrite with brand + keywords.
- Brand name is inconsistent across tags (`Amjunlimited` / `AMJUnlimited` / `AMJ Unlimited LLC`) — standardize.
- Open Graph and Twitter Card tags are complete but inherit the weak title.
- Duplicate `WebSite` JSON-LD block; `LocalBusiness` schema is thin (missing hours, priceRange, geo).
